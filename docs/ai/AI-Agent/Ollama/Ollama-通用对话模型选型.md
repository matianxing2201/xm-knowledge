# Ollama 通用对话模型选型

## 一、主流对话模型一览

- Llama 系列
- Qwen（通义千问）系列
- Mistral 系列
- 其它（Gemma / Phi 等）

## 二、按资源选择

- 不同参数量适合的硬件
- 量化版本的选择

## 三、按场景选择

- 中文能力
- 推理能力
- 指令跟随
- 长上下文

## 四、一个选型决策树

## 五、小结

1. 常见对话模型包括 Llama、Qwen、Mistral、Gemma 和 Phi 等系列。
2. 先根据可用内存和计算能力缩小选择范围，再考虑参数规模和量化版本。
3. 中文能力、推理、指令跟随和上下文长度等表现会因模型而异，应结合实际任务比较。
4. 用本机任务样例试跑候选模型，再决定项目配置，通常比只看参数量更可靠。
