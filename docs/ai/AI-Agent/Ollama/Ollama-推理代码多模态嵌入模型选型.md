# Ollama 推理 代码 多模态 嵌入模型选型

## 一、推理模型

- DeepSeek-R1 / QwQ 等推理模型
- 思考链与长输出场景

## 二、代码模型

- Qwen-Coder / CodeLlama 等
- 代码生成 / 补全场景

## 三、多模态模型

- LLaVA / Llama 3.2 Vision 等
- 图像理解场景

## 四、嵌入模型（Embedding）

- nomic-embed-text 等
- 与 RAG 场景结合

## 五、选型建议与汇总表

## 六、小结

1. 推理模型侧重复杂推理和较长的思考过程。
2. 代码模型更适合代码生成、补全等编程任务。
3. 多模态模型可以处理图片与文字输入，适用于图像理解。
4. 嵌入模型把文本转换为向量，常用于相似度检索和 RAG。
5. 选型时需要结合任务类型和设备资源，实际测试效果后再确定模型。
