# Ollama 模型概念

## 一、参数（Parameters）

- 7B / 8B / 70B 等参数量含义
- 参数量对效果与资源的影响

## 二、量化（Quantization）

- Q4_K_M / Q5 / Q8 等量化格式
- 量化带来的体积、显存、精度权衡
- Ollama 里量化 tag 的写法（如 `q4_k_m`）

## 三、上下文窗口（Context Window）

- `num_ctx` 的作用
- 上下文窗口与显存的关系
- 超窗的截断与策略

## 四、Dense 与 MoE 架构

- Dense 模型的参数全部激活
- MoE（混合专家）只激活部分专家
- 对推理速度 / 内存的影响

## 五、小结

1. 参数量描述模型规模，通常也会影响运行所需的内存和计算资源。
2. 量化通过降低权重精度缩小模型占用，需要在资源消耗与输出效果之间取舍。
3. `num_ctx` 控制模型可处理的上下文长度；上下文增大也会带来更高资源占用。
4. Dense 模型会使用全部参数，MoE 则按输入激活部分专家，二者的计算和内存特点不同。
