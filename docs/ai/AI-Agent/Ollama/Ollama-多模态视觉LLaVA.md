# Ollama 多模态视觉（LLaVA）

## 一、多模态模型选型

- LLaVA 等视觉语言模型

## 二、拉取并运行视觉模型

- `ollama pull llava`

## 三、图片理解示例

- 输入图片 + 提问，返回图片内容的描述
- Python SDK 传入 `images` 参数

## 四、结合对话做图像分析

- 多轮追问同一张图
- 识别 / OCR / 场景理解场景

## 五、小结

1. 视觉语言模型可以接收图片和文字问题，并返回文本结果。
2. 使用前需要拉取并运行支持图片输入的模型，例如 LLaVA。
3. Python SDK 调用时，将图片和问题一并传给模型。
4. 图片理解可用于描述、OCR 和场景分析，也可以在多轮对话中继续追问。
